# LeetCode 75 — Python Solutions

A personal, bilingual (English/Spanish) collection of Python 3 solutions to a curated set of 75 coding problems. The problem numbers are this repository's own order, not LeetCode problem IDs.

**Solution files:** 75/75 numbered problems have a Python file. This count tracks files, not verified correctness; some solutions still need fixes for edge cases.

**Website:** [ariana0505.github.io/leetcode75-python](https://ariana0505.github.io/leetcode75-python). The site builds its problem catalog from the linked rows below and reads each directory's `statement.md` and Python file.

## How to Run

Run any solution from the repository root:

```bash
python3 01-two-sum/two_sum.py
```

Most files are standalone scripts with example inputs; some define functions or classes without printing a result. The repository does not use a test framework.

## Website

The companion website is built with [Astro](https://astro.build/) in [`site/`](site/). It reads the linked problem directories in this README, along with their `statement.md` and Python files.

```bash
cd site
npm install
npm run dev      # local server at localhost:4321
npm run build    # static build in site/dist/
```

It is deployed to GitHub Pages by GitHub Actions when changes are pushed to `main`.
