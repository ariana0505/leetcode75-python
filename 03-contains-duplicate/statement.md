# 5. Contains Duplicate / Contiene Duplicados

## English

Given an integer array `nums`, return `true` if any value appears at least twice in the array, and return `false` if every element is distinct.

### Examples

#### Example 1
```text
Input: nums = [1,2,3,1]
Output: true
Explanation: The element 1 occurs at the indices 0 and 3.
```

#### Example 2
```text
Input: nums = [1,2,3,4]
Output: false
Explanation: All elements are distinct.
```

#### Example 3
```text
Input: nums = [1,1,1,3,3,4,3,2,4,2]
Output: true
```

### Constraints

- 1 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9

## Espanol

Dado un arreglo de enteros `nums`, devuelve `true` si algun valor aparece al menos dos veces en el arreglo, y devuelve `false` si todos los elementos son distintos.

### Ejemplos

#### Ejemplo 1
```text
Entrada: nums = [1,2,3,1]
Salida: true
Explicacion: El elemento 1 aparece en los indices 0 y 3.
```

#### Ejemplo 2
```text
Entrada: nums = [1,2,3,4]
Salida: false
Explicacion: Todos los elementos son distintos.
```

#### Ejemplo 3
```text
Entrada: nums = [1,1,1,3,3,4,3,2,4,2]
Salida: true
```

### Restricciones

- 1 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9
