# 56. Palindromic Substrings / Subcadenas Palindromas

## English

Given a string `s`, return the number of palindromic substrings in it.

A string is a **palindrome** when it reads the same backward as forward.

A **substring** is a contiguous sequence of characters within the string.

### Examples

#### Example 1
```text
Input: s = "abc"
Output: 3
Explanation: Three palindromic strings: "a", "b", "c".
```

#### Example 2
```text
Input: s = "aaa"
Output: 6
Explanation: Six palindromic strings: "a", "a", "a", "aa", "aa", "aaa".
```

### Constraints

- 1 <= s.length <= 1000
- `s` consists of lowercase English letters.

---

## Espanol

Dada una cadena `s`, devuelve el numero de subcadenas palindromas que contiene.

Una cadena es un **palindromo** si se lee igual de izquierda a derecha que de derecha a izquierda.

Una **subcadena** es una secuencia contigua de caracteres dentro de la cadena.

### Ejemplos

#### Ejemplo 1
```text
Entrada: s = "abc"
Salida: 3
Explicacion: Tres subcadenas palindromas: "a", "b", "c".
```

#### Ejemplo 2
```text
Entrada: s = "aaa"
Salida: 6
Explicacion: Seis subcadenas palindromas: "a", "a", "a", "aa", "aa", "aaa".
```

### Restricciones

- 1 <= s.length <= 1000
- `s` consta de letras minusculas del alfabeto ingles.
