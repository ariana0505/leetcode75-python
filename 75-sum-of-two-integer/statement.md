# 75. Sum of Two Integers / Suma de Dos Enteros

## English

Given two integers `a` and `b`, return the **sum of the two integers** without using the operators `+` and `-`.

### Examples

#### Example 1
```text
Input: a = 1, b = 2
Output: 3
```

#### Example 2
```text
Input: a = 2, b = 3
Output: 5
```

### Constraints

- -1000 <= a, b <= 1000

---

## Espanol

Dados dos enteros `a` y `b`, devuelve la **suma de ambos enteros** sin usar los operadores `+` y `-`.

### Ejemplos

#### Ejemplo 1
```text
Entrada: a = 1, b = 2
Salida: 3
```

#### Ejemplo 2
```text
Entrada: a = 2, b = 3
Salida: 5
```

### Restricciones

- -1000 <= a, b <= 1000
