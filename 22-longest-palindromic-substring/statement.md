# 22. Longest Palindromic Substring / Subcadena Palindroma mas Larga

## English

Given a string `s`, return the longest palindromic substring in `s`.

A string is called a **palindrome** if it reads the same backward as forward.

### Examples

#### Example 1
```text
Input: s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.
```

#### Example 2
```text
Input: s = "cbbd"
Output: "bb"
```

### Constraints

- 1 <= s.length <= 1000
- `s` consists of only digits and English letters.

---

## Espanol

Dada una cadena `s`, devuelve la subcadena palindroma mas larga de `s`.

Una cadena es un **palindromo** si se lee igual de izquierda a derecha que de derecha a izquierda.

### Ejemplos

#### Ejemplo 1
```text
Entrada: s = "babad"
Salida: "bab"
Explicacion: "aba" tambien es una respuesta valida.
```

#### Ejemplo 2
```text
Entrada: s = "cbbd"
Salida: "bb"
```

### Restricciones

- 1 <= s.length <= 1000
- `s` consta solo de digitos y letras del alfabeto ingles.
